# Commands & Workflows

## Package Scripts

| Script        | Description                                                                                              |
| :------------ | :------------------------------------------------------------------------------------------------------- |
| `build`       | Builds the Nuxt application for production.                                                              |
| `dev`         | Runs the Nuxt application in development mode.                                                           |
| `generate`    | Generates the Nuxt application for static deployment.                                                    |
| `preview`     | Locally previews the Nuxt application after a build.                                                     |
| `postinstall` | Prepares the Nuxt application after dependencies are installed, typically for build-time optimizations.  |

## CLI Commands

* `node scripts/seed_tribeca_2026_awards.cjs` — Seeds the `festival_awards` table with 2026 Tribeca Festival feature film award winners.

## CI Workflows

* [gitset-knowledge.yml](../../.github/workflows/gitset-knowledge.yml): Refreshes the project's AI knowledge base using Gitset and creates a pull request for changes. Triggered on `workflow_dispatch` and `push` to `main` (excluding docs, markdown, gitignore, LICENSE).
* [sync-hero-data.yml](../../.github/workflows/sync-hero-data.yml): Automates synchronization of hero and noir enrichment data, then commits and pushes updated JSON files. Triggered hourly at minute 0 past hour 6 (`cron: 0 6 * * *`) and on `workflow_dispatch`.
* [sync-noir-historical.yml](../../.github/workflows/sync-noir-historical.yml): Automates synchronization of N.O.I.R historical data and regenerates noir enrichment data, then commits the updated JSON file. Triggered on `workflow_dispatch`.
