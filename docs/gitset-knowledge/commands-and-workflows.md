# Commands & Workflows

This document outlines the command-line interface (CLI) commands, package scripts, and continuous integration (CI) workflows for the Cinemagoria project.

## Package Scripts

The following scripts are defined in the [package.json](../../package.json) file:

| Script      | Description                                          |
| :---------- | :--------------------------------------------------- |
| `build`     | Builds the Nuxt application for production.          |
| `dev`       | Starts the Nuxt development server.                  |
| `generate`  | Generates the Nuxt application as static files.      |
| `preview`   | Previews the Nuxt application in production mode.    |
| `postinstall` | Prepares the Nuxt application after installation.    |

## CLI Commands

*   `node scripts/seed_tribeca_2026_awards.cjs` — Seeds the `festival_awards` table with 2026 Tribeca Festival feature film award winners.

## Common Tasks

*   **Building for Production**: To build the application for deployment, run `npm run build`.
*   **Running Locally**: For local development, use `npm run dev`.
*   **Generating Static Site**: To generate a static version of the site, execute `npm run generate`.
*   **Previewing Production Build**: To preview the production build locally, run `npm run preview`.
*   **Post-installation Setup**: After installing dependencies, ensure Nuxt is prepared by running `npm run postinstall`.
*   **Automating Docker Deployment**: The [cloudbuild.yaml](../../cloudbuild.yaml) file configures Google Cloud Build to automate the Docker image build, push to Artifact Registry, and deployment to Cloud Run for the `cinemagoria-main` service in `us-east1`.
*   **Refreshing AI Knowledge Base**: The `gitset-knowledge` CI workflow automatically refreshes the project's AI knowledge base.
*   **Synchronizing Hero Data**: The `sync-hero-data` CI workflow synchronizes hero selection data.
*   **Synchronizing N.O.I.R. Historical Data**: The `sync-noir-historical` CI workflow synchronizes N.O.I.R. historical data and regenerates enrichment data.
