Strip C, with the old logo's materials

The Strip C idea from the last round, rebuilt with the current logo's relief: a cyan face with teal side walls, sprocket holes with depth, the matte gray recess behind the play, and the play button itself. Three versions, each beside the current logo.

Side by side

E1 uses the play cut pixel for pixel from the current logo. E2 redraws it as a vector with the same colours, side wall and highlight. E3, the selected version, keeps the gray only inside the C and uses the same original play as E1, which is sharper and lighter at small sizes than the vector redraw.

Comparison sheet

Same sizes and surfaces for every row. One-colour versions fall back to the flat C, because relief and gloss cannot be printed in one ink. The 16 px column magnified 3× shows real device pixels.
